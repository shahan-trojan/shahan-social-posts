# shahan-social-posts

Public files of posts Shahan has **approved**, put here by his social engine a few minutes before they go out on his
Facebook Page, Instagram and LinkedIn. Instagram and Facebook only accept images and videos from a public web link;
this folder is that link (Cloudinary copies each file from here).

- One folder per post: `<date>_<post>/`.
- Nothing unapproved, private or draft is ever put here.
- `_setup_check/` is a one-time test image of the publishing route.
